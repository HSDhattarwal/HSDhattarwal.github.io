# Harender Dhattarwal — GitHub Pages site

This is a lightweight, professional static website (no build step) prepared to replace the prior Google Site.

## Deploy (GitHub Pages)

1. Create a GitHub repository.
   - **User/Org site:** name it `<username>.github.io`
   - **Project site:** any repo name is fine

2. Upload the contents of this folder to the repository root.

3. In GitHub: **Settings → Pages**
   - Source: `Deploy from a branch`
   - Branch: `main` / `/ (root)`

4. Open your published URL.

## Editing content

- `index.html`: hero/about/contact + replace the placeholder LinkedIn/Scholar URLs.
- `publications/index.html`: publications list.
- `tccb/index.html`: TCCB description and schedule data (embedded JSON).

## Notes

The TCCB flyer images on the Google Site were not publicly retrievable in all cases. Add your own PDFs/images under `assets/` if desired.
